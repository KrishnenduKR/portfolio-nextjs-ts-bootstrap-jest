This is a Portfolio site project created using [Next.js], typescript and bootstrap.

View the deployed site in [https://portfolio-nextjs-ts-bootstrap-jest.vercel.app/](https://portfolio-nextjs-ts-bootstrap-jest.vercel.app/)

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
