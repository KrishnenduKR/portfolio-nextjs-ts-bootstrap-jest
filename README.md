This is a Portfolio site project created using [Next.js], typescript and bootstrap.

View the deployed site in [https://portfolio-nextjs-ts-bootstrap-jest.vercel.app/](https://portfolio-nextjs-ts-bootstrap-jest.vercel.app/)

## Getting Started

clone project

```bash
Insall dependencies
-npm install

run dev server
-npm run dev

```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result and modify the contents and styles according to your favour to change into your own portfolio site.
